# MRO Sourcing Toolkit · 采购比价与供应商评估工具

面向 **MRO / 间接采购** 场景的轻量分析工具：把多供应商报价表丢进去，自动拉平口径、算出到货总成本、给出供应商评分与份额建议，并输出可直接用于评审会的 Excel 报告。

> 设计初衷：采购比价最容易出错的地方不是「找最低价」，而是**口径不一致**——
> 13% 专票和 3% 小规模纳税人的报价不能直接比、单价低但运费高未必真便宜、
> 起订量高于需求量会把总成本抬高、资质不全的低价供应商在医药化工行业根本不能用。
> 这个工具把这些坑全部显式化。

---

## 一、核心能力

| 模块 | 做什么 | 关键口径 |
|---|---|---|
| **询价比价** | 多供应商报价横向对比，输出比价矩阵与最优劣汰建议 | 不含税单价、到货等效单价（含运费、含 MOQ 摊薄） |
| **供应商评分** | 价格 / 交期 / 质量 / 服务 / 资质 五维加权打分，输出排名与建议份额 | 权重可配置并自动归一化；资质不全触发扣分 |
| **风险识别** | 单一来源、价差异常、MOQ 陷阱、账期风险、合规排除 | 合规优先于价格 |
| **库存补货** | ABC 分类 + EOQ + 安全库存 + 再订货点 | SS = Z·σ_d·√LT，ROP = d·LT + SS |
| **报告输出** | 5 个 Sheet 的 Excel 报告（含色阶条件格式与图表） | 汇总 / 矩阵 / 明细 / 评分 / 建议 |

## 二、快速开始

### 方式 A：命令行（Python）

```bash
git clone https://github.com/<your-name>/mro-sourcing-toolkit.git
cd mro-sourcing-toolkit

python -m mro.cli init        # 生成 Excel 模板
python -m mro.cli demo        # 用内置示例数据跑一遍，输出 output/demo_report.xlsx
python -m mro.cli run -q data/sample_quotes.xlsx -i data/sample_inventory.xlsx -o output/report.xlsx
python -m mro.cli score -q quotes.xlsx       # 只看供应商评分
python -m mro.cli inventory -i inventory.xlsx
```

**依赖**：核心引擎**零第三方依赖**（纯标准库）；只有读写 `.xlsx` 需要 `openpyxl`。

```bash
pip install -r requirements.txt     # 仅 openpyxl
```

未安装 openpyxl 时，报告会自动降级为多文件 CSV 输出，不会中断。

### 方式 B：网页版（零安装）

直接用浏览器打开 `web/index.html`：内置示例数据、可上传 Excel/CSV、可调权重、可导出 Excel 报告。
**全部计算在浏览器本地完成，数据不出本机**，也无需任何后端。

> 网页版与 Python CLI 采用**同一套口径与权重**，已做过逐条对账（48 条报价记录结果完全一致）。

## 三、输入表结构

表头支持中英文混写，至少需包含 `物料编码 / 物料名称 / 供应商 / 单价 / 需求数量`。

| 字段 | 必填 | 说明 |
|---|:--:|---|
| 物料编码 / 物料名称 / 规格型号 / 单位 | ✓ | 用于聚合与展示 |
| 需求数量 | ✓ | 请购量 |
| 供应商 / 单价 | ✓ | 报价主体 |
| 税率 | | 默认 13%，**填 0 表示免税**（不会被默认值覆盖） |
| 是否含税 | | 是 / 否，默认「是」 |
| 交期 | | 天，填 0 表示现货 |
| 最小起订量 MOQ | | 高于需求量时按 MOQ 计算下单量 |
| 运费 | | 按含税填，内部折算不含税后计入到货成本 |
| 付款条件 |  | 如「月结30天」「预付全款」，用于现金流风险提示 |
| 质量评分 / 服务评分 | | 0–100，缺省按 80 计 |
| 资质合规 | | 是 / 否，医药化工场景建议开启合规优先 |
| **历史单价** | | **请填不含税口径**，用于计算降本率 |

## 四、计算口径（这部分是项目的技术核心）

```
不含税单价   = 含税单价 ÷ (1 + 税率)          ← 税率不同的报价必须拉平
实际下单量   = max(需求数量, 最小起订量)        ← MOQ 会把实际支出抬高
到货总成本   = 不含税单价 × 实际下单量 + 不含税运费
到货等效单价 = 到货总成本 ÷ 实际下单量          ← 跨供应商横向对比的唯一正确口径
降本率       = (历史不含税单价 − 到货等效单价) ÷ 历史不含税单价
安全库存 SS  = Z × σ_d × √LT                  ← Z 由服务水平决定（95% → 1.645）
再订货点 ROP = 日均需求 × LT + SS
经济批量 EOQ = √(2DS / H)，H = 单价 × 持有成本率
```

**为什么小规模纳税人的报价要小心**：含税价同为 113 元时，13% 专票的不含税成本是 100 元，
3% 专票是 109.71 元——**含税价一样，实际成本差 9.7%**。直接比含税价会选错供应商。

## 五、示例输出

内置示例为「某医药化工企业 MRO 季度询价」：12 个物料、4 家供应商、48 条报价，
刻意混入不同税率、含税/不含税混报、运费差异、MOQ 陷阱与资质缺失。

```
物料数 12 · 报价条目 48 · 供应商 4
选定总金额(不含税)   ¥79,662.42
比价节约金额         ¥18,533.68   （比价节约率 18.87%）
相对历史价降本率     16.93%
```

| 排名 | 供应商 | 综合得分 | 价格分 | 交期分 | 资质分 | 低价命中 | 建议份额 | 等级 |
|:--:|---|--:|--:|--:|--:|--:|--:|---|
| 1 | 广联机电 | 92.62 | 89.57 | 100.00 | 100 | 3 | 60% | A级-战略供应商（建议主供） |
| 2 | 华创工业物资 | 90.70 | 90.82 | 86.67 | 100 | 6 | 30% | A级-战略供应商 |
| 3 | 瑞科供应链 | 74.25 | 75.75 | 33.33 | 100 | 3 | 10% | C级-观察/整改 |
| 4 | 通达五金 | 50.11 | 95.08 | 0.00 | **0** | 0 | 0% | D级-建议淘汰 |

> 通达五金价格分最高（95.08）却排最后：**资质不全触发合规扣分，交期 20 天也最差**。
> 这正是只看单价会踩的坑——低价背后是合规与交付风险。
